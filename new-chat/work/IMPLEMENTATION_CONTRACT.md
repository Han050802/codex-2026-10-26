Shared db.py API:
- ApiError(status:int, message:str, details=None), attrs status/message/details.
- connect(db_path): sqlite connection, row_factory sqlite3.Row, foreign_keys on, busy_timeout. Use standard deferred isolation and `with conn:` for mutations; no outer request transaction. WAL configured on initialization.
- now(): ISO local timestamp or UTC timestamp consistently.
- audit(conn,user,action,entity,entity_id,detail): insert audit_logs row, no commit itself. user dict has id,username,name.
- amount(value): accept integer fen ONLY (bool rejected), >=0 unless caller explicitly supports negative. UI converts decimal currency to fen.
- initialize(db_path) calls finance.init_schema(conn). finance imports shared functions above.

Server dispatch calls `finance.handle(conn, method, path, payload, user, query)` for /api/books/... paths. `path` is URL path string, `query` dict of str -> str (first query value). Return JSON-compatible dict/list; unknown route returns None; raise ApiError. Each write handles own transaction and audit. Server supplies authenticated user, enforces CSRF, same-origin and payload limits. JSON failures have `{error:string, details?:...}` and proper status.

Core APIs:
GET /api/session -> {user:{id,username,name}|null,csrf:string|null,setup_required:bool,demo:bool}
POST /api/setup {users:[{username,name,password} x3], company_name} -> session. Initial setup ONLY via loopback + one-time setup token header X-Setup-Token created by launcher (do not log passwords).
POST /api/login {username,password} -> session; POST /api/logout.
GET /api/bootstrap?period=YYYY-MM -> {clients,users,invoices,notes,contracts,receipts,projects,tax_records,book_periods,settings,audit_logs,help_articles,demo}.
POST /api/clients; PATCH /api/clients/{id}; DELETE = soft recycle; POST /api/clients/{id}/restore. JSON client fields id,name,code,taxpayer_type('small'|'general'),standard('small2013'|'enterprise2007'),industry,region,start_period,accountant_id,enabled,labels:[str],service_status,note,version,deleted. Initialize finance accounts on creation (finance.ensure_book(conn,client)).
POST /api/notes {client_id,text}; saved follow-up notes; PATCH client.note is quick memo.
POST /api/invoices; PATCH /api/invoices/{id}; DELETE unposted only. Fields client_id,period,kind('input'|'output'|'expense'),number,date,category,summary,amount_fen,tax_fen,total_fen,status('unprocessed'|'posted'),voucher_id,attachment_id,version. Real server validates sums/duplicate invoice number. POST /api/invoices/{id}/post {debit_account,credit_account,tax_account?} calls finance.create_invoice_voucher(conn,invoice,payload,user); finance returns voucher_id and uses same enclosing transaction, no commit. Invoice becomes posted atomically. No fake OCR or live tax collection.
POST /api/contracts; PATCH /api/contracts/{id}; fields client_id,service,start_period,end_period,monthly_fee_fen,status('active'|'terminated'),note,version. GET bootstrap calculates due_fen,received_fen,debt_fen,prepaid_fen at selected period, monthly fee includes every month in [start,end] up to selected period. Keep distinction lifetime contract value and due as-of selected period.
POST /api/receipts; fields contract_id,date,amount_fen,method,note. Positive amounts; no edits to receipts, POST /api/receipts/{id}/reverse creates explicit reversing record, audit. Tie receipt to contract/client.
POST /api/projects; PATCH /api/projects/{id}; fields client_id,name,type,status,due_date,assignee_id,steps:[{title,done,note,completed_at,completed_by}],version. Server timestamps and records actual executor when steps complete.
POST /api/tax-records; PATCH /api/tax-records/{id}; fields client_id,period,tax_type,status('pending'|'preparing'|'submitted'),payment_status('unpaid'|'paid'),confirmation_status('pending'|'confirmed'),amount_fen,paid_fen,reference,source('manual'|'import'),attachment_id,note,version. Validate full batch first; commit none on invalid rows. Return imported count/error row details. GET /api/backup authenticated zip download consistent SQLite backup plus files; POST /api/settings company and basic policy settings; GET /api/help?q= local help search grounded in app functions. Finance APIs (finance owner confirms exact bundle):
GET /api/books/{client_id}?period=YYYY-MM -> {client,period,accounts,opening_balances,vouchers,trial_balance,ledger,reports,assets,inventory_items,inventory_movements,payroll,periods,checks,journals}. JSON standard forms agreed in message.
POST /api/books/{id}/accounts {code,name,direction,category,report_key}; initialize realistic standard-specific chart.
POST /api/books/{id}/opening {balances:[{account_code,debit_fen,credit_fen}]} -> balance checks; lock after use/close appropriately.
POST /api/books/{id}/vouchers {date,summary,lines:[{account_code,debit_fen,credit_fen}],source_type?,source_id?}; PATCH /vouchers/{voucher_id} includes version; DELETE /vouchers/{id} voids; POST /vouchers/{id}/review {reviewed:bool,version}.
POST /api/books/{id}/close {period}; POST /reopen {period}; close creates profit/loss carry-forward voucher if needed, checks balancing and affected accounts; latest-first reopen, prevent writes to closed periods. No duplicate auto vouchers.
POST /api/books/{id}/assets; POST /assets/depreciate {period}; POST /assets/{asset_id}/dispose. Asset card, straight-line depreciation excluding residual, generated vouchers, idempotent monthly accrual.
POST /api/books/{id}/inventory/items; POST /inventory/movements; weighted-average outbound cost, no negative stock, purchases/outbound generate linked balanced vouchers, control backdating.
POST /api/books/{id}/payroll; POST /payroll/post {period} generates accrual voucher, imported/manual withholding fields, net pay calculated, avoid duplicate voucher. Do not invent tax calculations.
POST /api/books/{id}/journals; journal date,summary,bank_account,counter_account,direction('income'|'expense'),amount_fen; POST /journals/{id}/post generates balanced voucher once. finance.create_bank_journal(conn,client_id,row,user) for import; no nested commit.
Finance exports provide `export_rows(conn, client_id, kind, period)` -> (headers:list[str], rows:list[list]) for bank/vouchers/trial-balance; server writes CSV.
