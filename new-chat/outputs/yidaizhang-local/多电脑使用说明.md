# 在多台电脑使用和修改代账台

办公室只运行一份正式账套：现有主机保存账务、原件和账号，其他电脑用浏览器登录主机地址。修改程序通过同一个 GitHub 仓库同步。

## 在另一台电脑处理账务

将维护人员提供的“代账台-其他电脑使用”文件夹完整复制到另一台电脑，双击“打开代账台.cmd”，用已有账号登录。两台电脑应连接同一办公室路由器，主机保持开机。这个入口带连接诊断和浏览器直连设置。

在一台电脑保存业务后，另一台刷新对应页面即可看到更新。多人同时修改同一条记录时，后保存的人可能收到“已被修改”提示，刷新后重新核对，避免覆盖他人改动。

主机地址变化后需要重新生成入口。客户端不需要安装 Python，也不用复制数据库。

## 在另一台电脑修改页面和功能

1. 双击“准备修改程序.cmd”。首次会通过 Windows winget 安装缺少的 Git、Python 3.12，再下载本仓库；安装可能需要 Windows 确认。源码保存在 `%USERPROFILE%\source\daizhangtai\new-chat\outputs\yidaizhang-local`，桌面生成“代账台程序源码”入口。已有开发目录会保留。
2. 在 Codex 中打开该源码文件夹。开始修改前双击“拉取程序更新.cmd”；完成修改并通过相应检查后，双击“提交程序修改.cmd”。首次提交需要配置 Git 姓名和邮箱；首次推送需要登录有仓库写权限的 GitHub 账号。
3. 回到正式主机，先让同事保存当前操作，双击“拉取程序更新.cmd”。看到成功后，先运行 `stop.cmd`，再运行 `start.cmd`，其他电脑刷新页面即可使用新功能。不要在其他电脑启动正式账套。

同步遇到本地未提交更改、远端有新提交、分叉或其他已暂存文件时会停止并说明原因。保留现场，让 Codex 处理冲突后再继续。不要使用强制覆盖命令处理账务系统的程序更新。

程序更新不会自动重启正在运行的主机服务。源码同步只提交应用目录中明确允许的源文件；账务、账号、上传原件、备份和报表留在主机。程序中不可硬编码密码或客户资料。
