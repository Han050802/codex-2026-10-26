# 易代账本地工作台

## GitHub 源码

源码仓库：[Han050802/codex-2026-10-26](https://github.com/Han050802/codex-2026-10-26)，本应用位于 `new-chat/outputs/yidaizhang-local`。仓库同步源码、页面资源和测试；本地账套、账号配置、上传原件、导出报表及更新备份均不随源码上传。演示样例使用合成数据。

安装 Python 3.12 后，可在终端下载并启动：

```powershell
git clone https://github.com/Han050802/codex-2026-10-26.git
cd codex-2026-10-26/new-chat/outputs/yidaizhang-local
python launcher.py
```

首次运行会创建本机数据目录并打开账号设置页面。GitHub 保存源码，实际账务服务仍在本机运行。基础记账功能使用 Python 标准库；PDF 文字提取和图像识别还需运行环境提供 `pypdf`、`Pillow`、`rapidocr-onnxruntime` 和 `pypdfium2`。当前 OCR 优先调用用户目录下的 Python 3.12，迁移电脑时请核对该解释器及依赖。前端无需构建；安装 Node.js 后可运行 `npm run check` 检查脚本语法。

## 首页凭证统计与按月查看

公司首页“凭证”卡片的总数和附件数按顶部所选月份统计；点击任一数字，会重新读取该月有效凭证并清除先前的搜索、状态和金额筛选。卡片下方“全部期间”汇总本账套全部有效凭证，点击“按月查看”可选择历史月份，进入其真实所属账期。已作废凭证、期初余额和未入账的结转测算不计入凭证张数。

附件显示凭证登记的单据张数，不等同于归档文件份数。进入凭证后点击“原件与依据”可查看已关联的上传原件和核对依据。

## 核对后的凭证查看

进入客户账套的“流水发票核对”，顶部自动列出该客户已保存的核对记录和已生成凭证，覆盖以往月份的发票核对与回单制证。点击“查看凭证”会进入该凭证的真实所属月份并定位到对应凭证；当前核对结果也有同样入口。“原件与依据”独立显示关联资料，历史未留存原件不影响查看实际凭证。

重新打开页面后仍能读取已保存的凭证；读取失败时保留已展示记录并提供刷新重试。尚未制证的核对记录继续显示为待处理。列表最多显示最近500张核对来源凭证，达到上限时会提示，可在账簿按月份查看更早记录。

## 原件与凭证关联归档

在客户账套的“流水发票核对”中识别 PDF、图片或 ZIP 后，系统保存原始上传文件、ZIP 原包及识别成员、原始识别结果。匹配保存或制证时，同时关联实际使用的数据、核对与科目判断依据；识别后人工更正的数据与原始识别结果分别保留。

识别页面点击“查看已归档原件”，可查看本批全部原件；核对结果、已保存记录及凭证列表点击“原件与依据”，可查看对应凭证的资料，支持图片/PDF本地预览与原文件下载。重复处理不重复制证，也不覆盖首次制证时保留的依据；撤回或作废凭证后，历史资料继续保留。新归档随原有一致性 ZIP 备份与恢复。

上传识别前必须选择客户账套。历史上传未保存的原件无法自动补回，未关联的凭证会如实提示；样本演示不生成归档。

## 客户行业记忆

新建或编辑客户时，“所属行业”可选择已有行业，也可直接输入新行业。客户保存成功后，新行业自动存入后台词库；之后打开客户资料或批量调整行业时可搜索、选用，局域网其他电脑也共用同一份词库。已有客户的行业自动补入，重复名称不重复登记；客户改行业或移入回收站后，原行业仍可选用。

## 合同到期与续约提醒

首页“代账进展”同时显示服务合同期限和每月记账、申报进度。“收费到期”按合同最后服务月份显示，于该月月末到期；到期当月显示黄色文字和“请询问是否续约”，已过期显示红色提醒，并汇总当前筛选范围内的待跟进数量。日期到期后保留公司账套，由员工联系客户确认续约或终止。

点击该公司的“收费到期”或“未签合同 · 设置”，即可打开对应合同，填写 `YYYY-MM` 或点击“选月份”选择年份和月份。保存后列表同步更新，连续续签后延长到新的到期月份；已终止合同不延长服务期限。有收款历史的合同保留原计费要素，可点击“续签合同”另建合同并自由选择新的到期月份。

## 首页快速查找公司

首页搜索栏输入公司名称的一部分、企业全称、客户编号、税号或已填写的助记码，即时列出匹配公司，点击结果直接进入该公司首页。搜索覆盖全部公司，不受表格分页、员工、标签、纳税性质或进度筛选限制；结果较多时可在下拉列表中滚动，支持方向键选择、回车进入及 Esc 收起。搜索后按放大镜或回车仍可筛选原有列表。

进入公司时保留首页选中的月份；若该月份早于公司建账月份，则进入建账月。回收站公司不显示，停用公司标明原因并需先启用后进入。此功能只读取已有公司资料和账套，不新增或更改账务。

## 余额表批量删除

余额表顶部点击“删除数据”，可按科目勾选或全选当前筛选范围内的来源记录，再点击“删除所选”核对凭证清单并填写原因。删除模式使用实际账面数据，退出后恢复原报表口径；折叠的明细仍包含在全选中，同一凭证只处理一次，每次最多 5000 笔。凭证会整张作废并保留审计记录，相关来源恢复为可重新处理；历史凭证计入期初余额时也会在确认窗口提示。已审核凭证、期初设置和结转测算不可选，已结账或他人修改过的数据由服务端拦截，任一来源无法删除时整批保留。

## 流水一级科目建议与多票核对

小企业会计准则账套的流水核对结合内置 P1–P5 分类规则与财政部小企业会计准则附录，按银行手续费及结息、薪酬税款、收款、租赁及资产、费用等顺序给出一级科目建议，并显示命中规则、判断依据及待核事项。没有发票时也可对符合规则的流水给出暂定建议；摘要不足以判断时显示待定。金额和比例只作为提示词中的分类线索，不能单独证明成本归属、资产确认或抵扣资格。税额抵扣和原有往来余额仍按实际资料判断。

单票匹配要求金额、双方名称和日期符合条件，日期应在同月或相差不超过 30 天。多票合计结果作为独立候选显示，不自动建立配对或凭证；候选组合超过一个、发票可能同时对应其他流水或日期不符时会提示。每笔流水同对手候选发票超过 14 张时不穷举组合。匹配金额与名称相同也不能保证实际业务关联。

发票或回单与流水唯一匹配后，系统直接生成实际凭证。科目按账套可用科目匹配；没有可用推荐时，收款使用其他应付款、付款使用其他应收款并保留分类依据。重复处理同一交易返回原凭证，不重复入账。

## 核对与业务科目匹配

匹配成功后直接入账，不再因缺少用途、资金科目或税额补充而停留在推荐状态。优先使用明确选择的资金科目，其余使用账套默认银行末级科目。税额信息完整可靠且有可用税费科目时拆分，否则按匹配总额入账，不补造税额，原始数据和自动处理依据保留。手工凭证、预付款和往来核销的专门入口保留原有校验。

## 核对后记入公司余额表

识别银行流水与发票后，优先使用流水户名；没有户名时，仅在金额及对方与发票唯一配对、能推断唯一本方名称时使用发票买卖方。识别出的本方公司名称与已有客户名称或企业全称唯一一致时自动选择该客户账套；没有匹配或存在重名时请手工核实。流水中的交易对方是往来单位，与保存账套的本方公司分别显示。识别或推断出的信息须结合原件核对。

识别完成并确认本方账套后，系统逐条核对并直接处理匹配记录。收入、支出及已匹配银行回单均生成借贷平衡的凭证；发票与回单同时匹配同一流水时共用一张凭证。样本演示不会写入账务。识别成功后，上传原件和原始识别结果按账套保存在本地；制证后可在凭证的“原件与依据”中查看。单据匹配不代表税务机关已查验发票。

保存成功后可点击“查看余额表”，定位涉及的期间和明细，另列本次凭证的借贷金额；期间发生额和期末余额包括其他记录，不一定等于本次单笔金额。按往来单位核算时系统查找或创建公司明细；上级科目已有直接发生额或期初余额时不能直接新增明细，需要先处理既有账务。流水金额列没有明确方向时会提示对照原件确认正负。

系统提供以[财政部小企业会计准则附录](https://kjs.mof.gov.cn/zhengcefabu/201111/P020111118325852734144.pdf)等资料为依据的科目规则，实际选择仍需核实交易性质、履约状态、既有凭证和税额；企业会计准则下预收业务还需结合[合同负债相关规定](https://www.csrc.gov.cn/jiangsu/c105409/c6940347/content.shtml)判断。

## 下级科目自动编号

在余额表的新增科目入口或“科目与期初余额”中选择上级科目，填写科目名称后保存。系统在上级编码后追加两位顺序号：例如 1122 下依次为 112201、112202；已有下级科目则从当前最大编号继续。不同账套、不同上级科目分别编号。保存前显示预计编码，实际编码以保存成功提示为准；多人同时新增时由服务端分配。每个上级的两位序号最多到 99，手工编码仍可使用。已有上级科目存在凭证分录或非零期初余额时，仍需按原有规则处理，不能直接增加下级。

## 余额表编号类目与总表导出

余额表中每个科目下的公司及用途均归为有编号的报表类目，每级追加两位：例如 `224101` 下依次为 `22410101`、`22410102`。相同公司与用途归入同一类目，按全账套数据统一分配编号，切换查询月份不会改变对应编码。报表类目保留原科目和凭证来源，点击可查明细；原凭证不因报表分类而重写。

“导出总表”独立读取建账至最新实际业务的完整账套，覆盖所有月份和年度，不受当前查询月份、科目筛选和折叠状态限制。总表显示累计发生额，父级与下级类目不会重复计入合计。

## 余额表科目选择

余额表的起始、结束科目选择窗口按资产、负债、权益、成本和损益分类，支持搜索、分页、选择和清空。小企业会计准则的新账套默认设置 68 个一级科目；已有小企业账套补充缺失科目时保留原有科目及明细，冲突项需核对。余额表默认隐藏没有余额和发生额的科目，可通过显示设置重新查看。科目 5901“以前年度损益调整”目前可在选择窗口中查看，但暂不支持凭证记账，避免错误计入当期损益。

## 流水发票自动核对

核对通过后，按财政部《小企业会计准则》附录及客户账套已有科目列出候选和适用条件。结果分别显示核对状态、分类依据与入账状态；流水备注中明确且与票面一致的业务用途可用于判断，项目名称本身不等于已确认用途。两种账套制度均按各自实际科目入账，既有账套制度不会被修改。

上传银行交易清单和发票文件后，系统核对金额和买卖方，读取发票项目、金额、税额及实际用途。识别不完整时可在页面补录。选择客户后，系统查询本机 SQLite 科目规则库，结合项目和用途列出候选科目、适用条件和需要核实的事项，并根据所选账套核对科目编码。页面中的“发票科目规则查询”支持按项目或科目检索规则和来源。多项目发票需逐项核实和拆分；个人往来不能仅凭姓名判断。

匹配成功即直接生成凭证，处理批次时也会重试本客户历史已匹配但尚未入账的记录。独立单据即使同日同额也可分别入账；相同交易标识和发票重复提交不会生成额外凭证。未匹配或存在实际交易身份冲突的项目显示原因。系统不会联网查验发票。

## 识别速度与提示

交易清单和发票分别显示已选文件与识别状态，可移除误选文件；识别后更换或移除文件会清除上一批界面结果，已经保存的记录不会自动撤销。上传后会逐文件显示识别状态和耗时；实际尝试第二方向的页面会标出。为避免本机资源争用，同一时间只运行一批识别；完成的结果临时保存在服务内存中，最多保留 15 分钟。机器识别的极小字号负号可能漏识，请特别留意流水金额与收支方向。

同批文件复用本地识别模型；发票字段和版面方向明确时只识别一次，无法确定时继续识别另一方向。识别失败、字段缺失或方向不明时显示具体提示，不再逐文件显示通用橙色警告。扫描 PDF 最多识别前 10 页，超过或无法确认页数时会提示。识别均在本机运行，机器识别仍可能出错。

## 已确认的七项优化（0.1.9）

三个会计显示名统一为“吕”“会计1”“会计2”，顶部、员工筛选、客户负责人和凭证制单人读取同一份账号资料；现有登录账号、密码、用户 ID 和业务关联保留。正式库初始化时默认填写这三个姓名。

公司工作区箭头、下拉和凭证分页统一为 SVG；禁用按钮使用真实 disabled。明细账和期初录入文字补齐为黑色。凭证录入弹窗加宽，常见电脑尺寸下六列可完整显示；新增凭证跨月保存后自动进入所属月份、清除遮挡该凭证的筛选并定位保存记录。明细账同日凭证按数值编号排列，余额表成功查询后右侧同步实际起止期间。

第 8 项账号姓名编辑和操作日志格式扩展暂未实施。

## 文字与登记状态（0.1.8）

凭证录入表头、输入内容、说明与合计改为黑色，首页及账表的浅色区域文字加深。公司工作区移除“小畅AI”浮窗，并统一优化导航、头像、铃铛与帮助图标。

首页进度按客户和月份读取真实记录：票据登记后显示“已登记·待制证”，制证后显示“已制证”；存在有效凭证后显示“已记账”，结账后显示“已结账”；税务登记后显示“已登记·准备中”，登记申报、缴款和客户确认后分别更新对应状态。作废、撤回或删除记录后重新计算，返回工作台和首页时自动重新读取数据。

## 公司首页、凭证与余额表（0.1.7）

在首页点击客户名称，进入该公司的独立工作区。公司首页、查看凭证和余额表按三张参考图还原布局；顶部公司名称可搜索切换客户，顶部账期与右侧月份栏同步。

- 首页点击“新增凭证”，可录入日期、摘要、附件张数及多条借贷分录；每条分录可分别填写摘要。保存后凭证、首页统计与余额表同步更新。凭证页支持搜索、编辑、审核、作废、分页和 CSV 导入导出。
- 首页点击“余额表”，在“全部科目”或表头齿轮菜单中新增科目、录入期初余额，也可进入科目与期初管理。期初借贷须平衡，已有凭证或结账时按原有规则锁定。余额由期初和有效凭证计算。
- 余额表支持期间范围、科目、级次、余额范围、零余额显示、层级展开、本年累计、明细账、打印及导出。不会重复累计上级科目与明细科目。
- 数据存于本机 SQLite 数据库，按公司和期间隔离。正式库及测试库均保留原有记录；截图中的业务数据不会自动加入运行库。

前三个页面已在外部 Chrome 核对。功能测试及页面截图中的合成业务只在独立临时数据库创建。

按提供的易代账截图制作的本地首版。由这台 Windows 电脑提供服务，其他电脑通过同一局域网的浏览器访问。页面、脚本和数据均保存在本机，不依赖 CDN，也不连接原易代账账号。

## 开始使用

1. 可双击 `demo.cmd` 打开独立本地测试环境。它会在系统默认的外部浏览器中打开，不使用 Codex 内置浏览器。
2. 测试账号为 `demo1`、`demo2`、`demo3`，测试密码均为 `DemoOnly123!`。新建环境的企业列表为空，启动时不会自动填入演示企业或示例业务；已自行添加的公司会保留。
3. 正式使用时双击 `start.cmd`。首次会打开仅限服务器本机的账号设置页面，请设置机构名称及三人的独立账号、密码。
4. 正式环境没有默认密码，也没有截图中的真实企业数据。三名用户均可修改业务，操作分别留痕；同一条记录同时修改时，后保存者会收到版本冲突提示。

正式地址为 `http://127.0.0.1:8765/`，演示地址为 `http://127.0.0.1:8766/`。启动器会显示这台电脑的局域网地址。在其他电脑打开“服务器的局域网 IPv4 地址 + :8765”即可，例如 `http://192.168.1.100:8765/`（示例地址）；地址以启动器当时显示的实际网卡地址为准。

服务器电脑需要保持开机，关闭网页不会停止服务。运行 `stop.cmd` 停止正式服务；运行 `stop.cmd --demo` 停止演示服务。程序没有更改防火墙或其他系统安全设置。若其他电脑连接不了，需要现场核对网段及现有网络访问规则。

“账套授权”保存本地分工名单，可替换、追加、移除或清空。它不限制访问，三名用户始终都能编辑。名单用于显示授权用户及“名下账套”筛选；“名下”同时包括指派会计和分工名单中的本人。

“按导入名单筛选”读取本地 CSV，只匹配已存在客户，不新增公司；可在筛选面板中更换或清空名单。批量新增仍使用独立的“批量导入”。行业调整、分工和删除都只处理选中客户，逐条显示成功及失败原因。

票据默认打开用户最新截图中的“小规模纳税人”页签；一般纳税人页签保留其对应参考图的表头。小规模页有纳税期限和金额预警，一般页有份数及人工核对入口。默认每页30条。取票客户列表的删除表示客户回收并保留票据和账务；在票据明细中删除才处理所选未制证票据。

“预约取票”保存本地待办，预约到期不会自动采集。任务管理支持新增、修改、本页/跨页全选和软删除，任务完成不会增加票据。“税务数字账户 / 进税局”查看本地客户资料及人工核对记录；“完善账密”打开本地资料，不收集税局密码；“更新认证状态”只保存人工核对来源。以上沿用参考图按钮标签，行为遵循已确认的本地业务范围。

纳税期限需要按客户实际资料选择月或季，系统不根据纳税性质猜测。金额预警仅统计当前筛选的小规模客户在本地登记的销项不含税金额；季度累计截至所选月，滚动12月也截至所选月。点击“金额预警”可修改提示阈值与临限比例，点击数字查看具体客户及金额。默认提示值来自参考页面，不作为正式税务计算或法定义务判断。

记账矩阵的绿勾由真实结账状态产生，已有有效凭证显示“进行中”，未开始和未建账分别显示。审核入口列出所选账套的真实待审月份，进入凭证逐张核对。装订打印先选择期间及凭证/科目余额内容，按公司分别生成全量预览；停用等无法读取的账套单独说明原因，不影响其他公司预览。

报税总览按最新截图保留验证、申报、缴款、检查四张卡片、收起按钮、原位置筛选栏、检查表头、横向滚动与底部分页。侧栏依次是报税总览、批量报税、报税设置、个税申报、报税记录、汇算清缴、工商年报和任务管理。默认无匹配时保留截图中的空列表引导，统计不会从已有公司数量推测生成。

开始报税检查：在“办税人管理”新增启用的联系人，为客户和期间建立本地匹配，核对资料并填写人工验证说明。完成匹配后，客户出现在本期检查列表中。点击单户“检查”或勾选后“批量检查”，系统逐户检查实际税务记录、回执证据、金额一致性及可选的未审核凭证、未制证票据提醒。结果可查看逐项原因、操作者和时间；未留存记录或证据不会显示检查通过。个税是否适用由会计明确设置，年度检查使用所关联的本地任务。

客户、办税人、税务记录、凭证、票据、检查规则或关联任务发生相关变化后，历史验证或检查结果标记过期，需重新核对或检查。配置、结果和人工登记都有独立版本和操作日志。“检查设置”只能开关提示规则，不能关闭身份、证据与金额核心检查。三名用户均能维护这些本地记录。

总览表头全选本页，选中后显示跨页全选与删除；删除客户进入回收站并保留税务及账务。报税设置中的删除只归档匹配；报税记录中的删除只归档所选本地记录。总览导出使用当前筛选和期间，记录页面的选中导出与批量准备按当前税种及所选记录执行。汇算清缴、工商年报和任务管理保存本地办理步骤；更正已完成步骤会把本地任务恢复为办理中。

客户选中导出、回收站选中导出、批量分配客户标签及批量结账统一支持多公司选择：

- 表头复选框选择或取消 **本页** 公司；部分选中时显示半选状态。
- “全选当前筛选”选择符合当前条件的 **所有页** 公司，旁边显示已选家数；“取消全选”清空选择。
- 翻页保留选择，修改搜索或筛选条件、切换业务页面时清空选择，避免把先前范围带入新操作。
- 批量结账按勾选公司执行，确认窗口列出公司与期间；未通过会计检查的公司会保留原状态并报告原因。

票据、流水、凭证等单条业务的“归属客户”仍用于确定唯一账套。CSV 批量导入按每行的客户编号归属数据。

票据、记账、报税、工商项目、收费等可维护业务列表也提供本页 / 跨页全选和批量移除，执行前显示记录清单，执行后逐条报告结果。删除客户或年度记账中的公司表示移入回收站，已有账务保留；回收站的空账套可彻底删除，有业务或历史记录的账套会阻止彻底删除。

未制证票据和流水可删除；已制证数据先撤回来源凭证。手工凭证通过作废保留审计，审核与结账保护仍生效。税务记录删除为本地归档，不向税局撤销申报或缴款。收款通过冲销记录纠错，有收款历史的合同不能直接删除。计算出的余额表、报表和期间状态需通过对应原始记录更正。

## 建账与日常处理

添加公司：进入 **客户 → 全部客户 → 新建客户**。页面按参考图显示“客户资料”，填写工商信息与财务设置后，点击底部“保存”。客户名称用于列表，企业名称保存完整登记名称，税号与助记码分别保存；内部客户编码由系统自动生成。保存后可从客户列表再次打开资料修改。

新建时须填写客户名称、企业名称、税号、行业、地区、企业形式、报税类型、指派会计、建账年月、会计制度及纳税性质。企业形式、地区、工商状态支持搜索选择。注册地址、经营地址和经营范围显示字数。指派会计表示工作分工，三名用户仍都能修改客户。

顶部页签定位基本信息、财务设置及税务资料三个分区，切换时保留输入。旧客户可分次补充新增资料。列表支持按客户名称、完整企业名称、内部编码、税号和助记码搜索，也提供启用 / 停用入口。

“从本地资料更新”接受一名客户的 CSV 或 JSON 文件，支持中文表头及对应英文公共字段名；先填入草稿，核对后再保存，不联网查询工商数据。身份证及密码需在面板单独填写。老板端设置用于保存本地老板联系人，不创建外部账号。

身份证号及工商年报密码加密保存在本机，保存后只显示已设置标识，重新编辑时留空保留原值；勾选明确清空才删除。加密资料依赖原 Windows 服务账号与 DPAPI 配置，换机或换 Windows 账号可能无法读取。程序会提示原环境恢复或明确清空重录，普通 ZIP 备份不能保证跨机解密。

创建客户时分别选择 **2013 小企业会计准则 / 2007 企业会计准则** 与 **小规模纳税人 / 一般纳税人**。这两项相互独立。选择启用期间后进入该客户的“进账簿”。

新账套可先设置借贷平衡的期初，再处理票据、资金流水与凭证。金额以整数分保存，分录必须借贷相等。报表从有效凭证和期初计算，修改后会重新取数。月结需要完成凭证审核、应计折旧、工资计提等检查；结账后该月锁定。

来源凭证不能直接改金额。发现录错时，在未审核、未结账且没有后续依赖的条件下，进入“凭证管理 → 撤回来源”，填写原因后重新处理。库存从该商品最新流水开始撤回；工资先撤发放再撤计提；资产先撤处置、最近折旧，再撤购置。原凭证和审计保留。手工凭证可在允许状态下修改或作废。

## 导入导出与外部业务

客户、票据、银行流水和税务记录提供 CSV 模板。用 Excel / WPS 打开模板，填写后另存为 **UTF-8 CSV** 再导入。金额列使用元，最多两位小数。银行流水导入需要先指定客户账套。

批量新增公司仍在客户列表的“批量导入”中操作。客户模板的 `code` 是须自行填写的唯一内部编码，标签列用 `|` 分隔；不同于单个客户面板自动分配编号。批量导入只新增，重复编码会导致整批失败，不会覆盖已有客户。

每批文件先验证，存在错误时整批不写入，并返回错误行。重复票据、重复流水、无效客户及科目、已结账期间等会被拦截。导出 CSV 带 UTF-8 BOM，可在 Excel / WPS 中打开。

票据和税务 CSV 的客户编号列为空时，可用导入窗口所选客户补齐；文件中显式填写的客户编号优先。导入前应核对整份文件中的归属客户。银行流水仍归属于导入窗口指定的单一客户账套。

附件支持 PDF、常见图片、CSV、XLSX 和文本，单文件最多 10MB。附件中的 XLSX 作为原件保存，不能直接作为批量导入表格解析。

按已确认范围，本地系统不执行联网取票、税务身份验证、正式开票、申报、缴款或银行转账。税务记录显示人工 / 导入来源；“发票开具”保存的是开票申请资料，不能作为有效税票。工资代扣税额由会计录入。

## 数据与备份恢复

- `data/`：正式数据库、附件和运行日志；首次启动正式服务后创建。
- `demo-data/`：独立本地测试数据库及日志，企业列表默认空白。
- `public/`：本地网页资源。
- `tests/`：后端业务、财务及 HTTP 自动化测试。

在“设置 → 数据备份”下载 ZIP。备份使用 SQLite 一致性快照，包含附件清单和内容校验值，不是直接复制一个运行中的数据库文件。

恢复正式数据的步骤：先运行 `stop.cmd`，再将备份 ZIP 文件拖到 `restore.cmd` 上执行。恢复程序会验证数据库完整性、关联关系和附件，并先在项目文件夹保存恢复前的备份。恢复后重新运行 `start.cmd`，用户需重新登录。

维护命令也可直接运行：

```text
python maintenance.py backup backup.zip --data-dir data
python maintenance.py restore backup.zip --data-dir data
```

请将备份另存到另一块可靠磁盘；仅保存在同一台电脑的数据目录不能应对整机磁盘故障。

## 核算范围与验收

当前科目模板分别包含小企业制度的基础科目与企业制度的常用非金融行业科目，可按规则新增明细科目。企业制度模板不覆盖所有行业及历次准则修订。

资产负债管理表、利润管理表由总账聚合；往来重分类、减值、递延税及其他期末调整需由会计录入和复核。现金流为按资金分录指定活动类型后的收支分类汇总，会显示未分类记录，不作为自动完成的法定现金流量报表。正式报送格式和行业专项核算需另外核对。

已验证范围见 `验收记录.md`。已在外部 Chrome 核对客户列表、票据主列表、年度记账矩阵及报税总览的实际布局与只读交互；未使用内置浏览器。没有提供参考图的内部弹窗按已确认的本地业务范围实现。三台独立电脑的局域网联测及实际会计业务验收仍需现场完成。请先使用独立测试库核对页面与业务流程，再开始正式建账。

## 运行环境

服务使用 Python 3.12 标准库，无需 npm 安装或前端构建。启动器已优先定位本机 Codex 附带的 Python；更换服务器电脑时，需要安装 Python 3.12 或调整启动脚本中的 Python 路径。其他两台客户端只需要浏览器。


## 标准表结转口径

余额表默认按标准表的损益结转口径汇总，财务费用贷方业务按借方负数冲减列示；按月补齐尚未实际生成的损益结转测算，12 月同时测算利润年结。已有真实结转凭证复用原来源，不重复测算。页面和 Excel 明确显示含未结转测算，测算不会生成凭证、审核凭证或锁定期间。标准视图整体只读，取消“按标准表结转口径”可查看和操作实际账面。

“导出总表”始终读取全账套的标准结转口径，保留真实起止期间及编号分类，父级与下级不重复计入合计。遇到无法对应的异常实际结转分录，标准报表明确提示核查，不静默隐藏金额；实际账面仍可查看。

### 首页工作进度

首页六列状态可点击，按所选公司与月份查看变化条件和对应记录，并可直接新增、编辑税务或票据记录，或进入凭证与期末结账。保存后首页与统计自动重新汇总。人工确认和缴款汇总包含个税；普通申报不含个税，个税单独统计。票据在保存后显示已登记，全部制证后显示已制证；记账依据有效凭证及结账状态计算。税务申报、客户确认及缴款通过人工登记或文件导入维护，不从税局自动同步。
