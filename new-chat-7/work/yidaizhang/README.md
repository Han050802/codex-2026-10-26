# 企业财务工作台

基于三张参考截图制作的交互页面。打开 dist/index.html 即可使用，也可在本目录运行 `python -m http.server 8000 --directory dist` 后访问 http://localhost:8000。

## 页面与操作

- 首页：按参考图还原导航、统计卡片、资金情况和帮助入口。
- 客户工作台：点击顶部“工作台”查看客户列表；点击客户名称进入公司首页。“公司资料”可补充联系人和备注。
- 公司切换：点击顶部公司名称选择其他客户。
- 凭证：左侧“总账”→“查看凭证”。支持搜索、条件筛选、新增、编辑、借贷校验、批量删除、CSV 导入导出和打印。
- 余额表：首页“余额表”或左侧“总账”→“余额表”。支持期间/科目/金额筛选、科目展开收起、明细查询、CSV 导出和打印。
- 账期：右侧月份栏或顶部账期输入可切换会计期间。

## 数据说明

这是界面与交互演示，未连接真实账务系统。截图中可读的公司名称、凭证和余额表数值作为演示数据；截图外的补充行用于展示滚动与科目层级。未提供的企业信息标记为“待补充”。凭证修改及补充的公司资料保存于当前浏览器 localStorage，各公司、账期独立存储，不跨设备同步。

采用纯 HTML、CSS、JavaScript，无需安装依赖。主要还原 1920×938 应用内容区，网页不包含浏览器工具栏或系统水印。
