AionUi Agent 错误排查与修复记录
日期：2026-10-26（北京时间）

已确认的故障
本机 AionUi 2.2.2 / AionCore 0.2.2 的 Codex 连接器未按线程区分通知。
当 Codex 0.163.0 的子任务完成时，AionUi 会提前结束主任务，之后丢失主任务最终答复，出现无归属输出、ChannelClosed 等状态异常。
本机 10 月 23 日日志与原始 Codex 会话记录存在三次主任务提前结束；隔离环境两次复现同一问题。
官方对应报告：https://github.com/iOfficeAI/AionUi/issues/4338
官方连接器源码：https://github.com/iOfficeAI/AionCore/blob/v0.2.2/crates/aionui-session/src/backend/codex_conn.rs

修补范围
使用 AionUi 自带 command_override 配置，给 Codex 入口增加本地协议适配程序。
适配程序继续调用原来的 Codex 0.163.0 原生可执行文件，只将属于主线程的通知交给 AionUi。
认证、审批请求、RPC 响应及全局通知保留；原 Codex 版本、模型与全局配置保留。
源码和原始可执行文件均保留，便于审查和撤销。

验证
1. Codex 普通单轮对话：通过。
2. Cursor 普通单轮对话：通过。
3. 未修补的 Codex 子任务场景：两次复现提前结束、丢失主任务最终答复。
4. 修补后的相同场景：主任务最终答复完整、无子任务文本串入、状态正常。
5. 同会话追加消息：通过。
6. 同会话重启恢复：会话 ID 保持，能继续回复。

其他独立问题
历史上有一次 Codex 进程被终止（退出码 1073807364），无法仅凭该日志判断终止者；本修补不声称能阻止所有外部进程终止。
Cursor 旧日志中的登录/初始化问题目前未复现，现有登录与普通对话测试正常。
Gemini CLI 仍有需要登录的记录；Aion CLI 历史 429 对应 Gemini 免费配额为 0，不能靠本地协议修补解决。
Antigravity 历史上另有无效 UTF-8 和 Windows 命令行过长错误；本次修补范围是已复现的 Codex 线程通知问题。
